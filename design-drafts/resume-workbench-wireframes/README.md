# Resume Workbench Wireframes

Static UI drafts for the future job-agent front end.

Open `index.html` in a browser, then compare the three directions:

- `draft-1-command-center.html` - dashboard-like layout with inputs, coach, match insight, and exports in one view.
- `draft-2-guided-flow.html` - step-by-step layout for first-time users.
- `draft-3-chat-first.html` - conversation-first layout with context and generated artifacts on side rails.

The drafts are intentionally frontend-only. They do not touch `models/`, `db/`,
or any phase package. The visual direction is warm, minimal, and inspired by
Claude-style product UI without copying brand assets.
