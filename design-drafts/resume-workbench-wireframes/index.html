Resume Workbench UI wireframe pack
Overview Command Guided Chat

Three clean UX directions for the job-agent UI.

Each draft keeps the same core workflow: resume input, JD input, a large interview coach area, tailored resume download, question bank and STAR story export, plus a fallback profile builder for users who do not have a resume ready.

One main work surface The user always knows where to ask questions and what context the answer uses.
Context before generation Resume and JD inputs sit close to the coach, so outputs feel grounded.
Artifacts stay visible Downloads are treated like generated assets, not hidden final steps.
